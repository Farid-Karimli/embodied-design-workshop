# Embodied Design with Computer Vision

A 45-minute hands-on workshop. Participants make an artwork respond to their hands and face through a webcam, then record a short video of themselves performing with it.

**Run it:** open `creative_vision_colab.ipynb` in [Google Colab](https://colab.research.google.com/) using Chrome, run the setup cell, and allow camera access.

- **Beginner track:** pick an artwork from the gallery, train your own gestures, then map signals to dials and gestures to actions.
- **Advanced track:** use MediaPipe's built-in gestures, write custom spatial mappings in JS, or build a new artwork in p5.js.

Built with MediaPipe Tasks (hands and face) and p5.js. Tracking and rendering run in the browser.
